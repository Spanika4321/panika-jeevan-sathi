# Product Hunt × GitHub

This repository is the **canonical product source** for [TEERNOVA](https://github.com/Spanika4321/panika-jeevan-sathi) on Product Hunt.

Product Hunt cannot be OAuth-connected from the repo itself. A maker must sign in on Product Hunt once and pick this GitHub repo. Everything below is ready to paste.

## 1. Connect GitHub on Product Hunt (one-time)

1. Open [Product Hunt](https://www.producthunt.com) and sign in (GitHub login is supported).
2. Go to **[Ship](https://www.producthunt.com/ship)** → **New product** (or **Launch**).
3. When asked for the product website / source, choose **Connect GitHub** and authorize `Spanika4321`.
4. Select repository **`Spanika4321/panika-jeevan-sathi`**.
5. Product Hunt will pull the name, description, README and topics from this repo.

If GitHub is already connected: **Settings → Account → Applications / Connected accounts → GitHub**.

TEERNOVA is a complete, production-ready Teer result platform for Assam Teer results. Every feature is free: live results, historical records, smart statistics, session information, and demo play with virtual credits only — no real money involved.
