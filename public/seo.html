Google Search Console

          

            Authorise the Google account that owns the property. The OAuth client ID, client secret and
            refresh token live only in this server’s environment and the encrypted database row — the
            browser never sees them.
          

          

        

        

          
AI engine

          

            Gemini is primary; the router falls back to any other configured provider, then to the
            deterministic rule engine. Whatever answered is recorded in the report.
          

          

          
        

      

      

        
Fil One object storage (report archive)

        

          S3-compatible storage used for the permanent report archive. Set FILONE_ENDPOINT, FILONE_BUCKET,
          FILONE_ACCESS_KEY_ID and FILONE_SECRET_ACCESS_KEY on this service. Until a real write/read probe
          succeeds the archive is shown as NOT_CONFIGURED or BLOCKED.
